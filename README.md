# Brawlhalla Autododge - Public Release

Copyright (c) 2026 Shyluko

This package is the end-user release build for Brawlhalla Autododge.

It is intended for people who only want to run the tool and do not need the full source tree. Keep the generated runtime folder plain, installable, and free of hidden developer-only paths.

## Files included

This package contains:

- `brawlhalla_autododge.exe`
- `brawlhalla_autododge.exe.debug`
- required runtime DLLs
- `config/`
- `data/`
- `LICENSE.txt`
- `README.txt`
- `README-UPLOAD.txt`

## How to use

1. Extract the zip file.
2. Keep the entire folder together.
3. Run `brawlhalla_autododge.exe`.
4. Do not move `config/` or `data/` away from the EXE.

## Important release rules

- Use a release build, not a debug build.
- Keep the debug-symbol file next to the EXE.
- Do not pack, obfuscate, or password-protect the archive.
- Keep the package free of personal machine paths or local developer references.
- Do not add Discord, Telegram, or recruiting/social links to the public package.
- Keep the runtime package plain and easy to install.
